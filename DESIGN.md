## Overview

Farseer is a Farcaster Mini App for follow-convergence detection. Users create
"Visions" — watchlists of trusted "Seers" — and receive "Omens" when multiple
seers follow the same account. The visual identity is **dark, mystical, and
precise**: a near-black canvas (`#0a0a0f`) with a single gold accent
(`#ffd54a`) for signals and interactions. The tone evokes an oracle or
cryptographic seer — minimal, high-signal, no decoration without purpose.

The grid is ruthless. Every element earns its place. Typography (system font)
carries hierarchy without extra boxes, icons, or color. Gold means "act here"
— buttons, unread indicators, convergence highlights. The app lives inside
Warpcast (Farcaster's client) so the phone-frame mockup is part of the design
language: 393×852px canvas, rounded corners, status bar.

## Colors

The palette is deliberately narrow — near-black surface, one gold accent, and
a purple for Farcaster platform badges. This constraint creates visual
coherence across the three tabs (Visions, Omens, Scrolls) and modal sheets.

- **Surface (`#0a0a0f`):** The app background. Deep enough to disappear on
  an OLED phone, making the gold accent the only thing pulling attention.
- **Surface container (`#181820` / `#121218`):** Cards, modal sheets, and
  input fields sit one step brighter than the background to establish depth
  without shadows.
- **Primary / Gold (`#ffd54a`):** The sole driver for interaction and
  attention — buttons, unread dots, convergence highlights, the FAB,
  active tab states, gold text accent.
- **Secondary / Purple (`#a5b4ff` with `#2a2d4a` background):** Farcaster
  platform badge only. Solid background ensures WCAG AA compliance.
- **Error (`#cc2244` on badges, `#ff4d6d` on inline states):** Destructive
  actions and notification badge backgrounds.
- **Success (`#4ade80`):** Positive states (connected, synced, confirmed).
- **Modal overlay (`rgba(0,0,0,0.7) + blur(8px)`):** Creates depth when a
  bottom sheet is open, keeping focus on the sheet content.

### Color application rules

1. **Gold is the only accent.** Never introduce a second accent color for
   interaction. Farcaster purple and X gray are platform identifiers, not
   interactive elements.
2. **Muted text (`#6b6b7a`) for metadata.** Timestamps, labels, secondary
   info. Readable but deliberately lower contrast.
3. **Red only for counts and destructive actions.** The badge count on the
   Omens tab and the `unfollow`/`remove` confirmations.
4. **Borders are barely visible** (`rgba(255,255,255,0.06)`). They provide
   structure without adding noise.
5. **Gradients are used sparingly** — only for the logo icon background and
   the primary button (gold gradient `linear-gradient(135deg, #ffd54a, #ffb300)`).
   Use token `{colors.primary}` as the fallback solid value.

## Typography

The app uses the **system font stack** (`-apple-system, BlinkMacSystemFont,
'Inter', system-ui, sans-serif`) for everything except metrics. This ensures
native rendering on every platform Warpcast runs on (iOS, Android, web).

- **Logo (17px / 700):** The only non-standard size. Gold-accented "Far" + white "seer".
- **Card titles (15px / 600):** Vision names, target names, seer names.
- **Body copy (13px / 400-500):** Most text — convergence descriptions,
  action text, modal body.
- **Labels (11px / 600 / uppercase / 1px tracking):** Section headers like
  "YOUR VISIONS", "SEERS (5)", form field labels.
- **Monospace (`'JetBrains Mono'`, 13px / 600):** Numerical data — seer counts,
  threshold values, alert counts. Creates visual distinction for metrics.
- **Stat numbers (18px / 700 / mono):** Large numbers in vision detail
  modals (omen counts, seer counts per target).
- **Status bar (11px / 700):** Phone frame time display.
- **Button text (15px / 700):** All primary and secondary action buttons.

## Layout & Spacing

### Grid and baseline

All spacing is based on a **4px unit**. The primary canvas is 393×852px
(phone frame).

### Key spacing values

| Token | px | Usage |
|---|---|---|
| `xs` | 4px | Small gaps between inline elements |
| `sm` | 8px | Icon-to-label gaps, small padding |
| `md` | 16px | Card padding, content padding horizontal, section gaps |
| `lg` | 24px | Modal sheet padding, panel padding, section breaks |
| `xl` | 48px | Large section separators |

### Layout rules

- **Content padding:** 16px horizontal, 12px vertical.
- **Card padding:** 16px on all sides. Omen cards use 14px vertical for tighter density.
- **Section gap:** 10px between cards, 12px between icon and label.
- **Sections:** 24px between major sections.

### Depth

Depth is achieved through color, not shadow. The hierarchy:

1. **Background (`#0a0a0f`)** — deepest layer
2. **Surface container-low (`#121218`)** — panels, inputs, secondary buttons
3. **Surface container (`#181820`)** — vision/omen/scroll cards
4. **Surface container-high (`#1c1c26`)** — cards on hover, elevated states
5. **Modal overlay** — full-screen blur layer (`rgba(0,0,0,0.7)` with `backdrop-filter: blur(8px)`)
6. **Modal sheet** — sits on top of the overlay
7. **FAB** — highest interactive element, with gold glow shadow

Full-width, panel background, subtle border. Used for "Cancel", "Close",

- **Background:** `surface-container-low` with `1px solid outline-variant` border

- **Typography:** `button-text` (15px / 700)

Small, uppercase labels identifying the tracking platform.

Slides up from the bottom for forms, detail views, and search.

- **Overlay:** `rgba(0,0,0,0.7)` with `backdrop-filter: blur(8px)`
- **Sheet:** Full-width, `background: #0a0a0f`, top corners 24px rounded
- **Drag handle:** 36×4px, `#4a4a58`, centered at top

### Tab Bar

Three items: Visions, Omens (with numeric badge), Scrolls.

- **Inactive:** Muted color (`#4a4a58`)

- **Badge:** Dark red background (`#cc2244`), near-black text (`#1a0000`)

### Pill Filter

Used on the Omens tab to filter by: All, Unread, Farcaster, X.

- **Inactive:** `surface-container-low` background, `#6b6b7a` text
- **Active:** Gold (`#ffd54a`) background, near-black (`#0a0a0f`) text
- **Shape:** 20px pill radius

### Floating Action Button (FAB)

Gold circle, positioned bottom-right. Used to create new Visions.

- **Size:** 52×52px
- **Background:** `surface-container-high` with gold text and border
  (prose: can also use gold gradient fill for higher emphasis)
- **Shadow:** Soft gold glow (`0 4px 20px rgba(255,213,74,0.25)`)
- **Position:** Fixed bottom-right, above tab bar

### Seer Avatar Stack

Overlapping avatars showing the seers in a Vision. Each avatar is 22px,
overlapping by -6px margin, with a subtle border. The last item shows "+N"

### Search Input

Used in the Add Seer modal. Search icon (16px) positioned 12px from left.

- **Padding:** 12px 14px with 40px left offset for icon
- **Background:** `surface-container-low`, subtle border
- **Focus state:** border becomes gold

## Do's and Don'ts

- **Do** use the gold accent sparingly — every gold element should signal
  something worth acting on.
- **Do** use system font for body text — it renders natively and matches
  Warpcast's own typography.
- **Do** use monospace for numbers — it makes metrics scannable.
- **Do** use `label-sm` (11px uppercase) for all section headers.
- **Don't** introduce a second accent color for interaction — gold is the
  only interactive accent.
- **Don't** use shadows on cards — depth is achieved through color layers.
- **Don't** add decorative icons, gradients, or flourishes — every element
  must carry information.
- **Don't** mix platform pools — Farcaster and X.com tracking are always
  visually and logically separate.
- **Don't** invent new border radius values — use the token set from
  `rounded:`.
- **Don't** hardcode hex values in components — always use token references
  (`{colors.primary}` not `#ffd54a`).
- **Don't** nest component variants — `omen-card-unread` is a sibling, not
  a child of `omen-card`.
